# 弹簧求解器：官方包逐字核对

2026-10-03｜来源：本机官方安装包 `Screen Studio.app` **3.4.4-3794** 的 `app.asar` → `dist/Df9pPW_a.js`。只读反混淆并还原算式；未执行其业务代码。3.7.5 的安装包已不在本机，但本文件核对到的常数与 3.7.5 静态研究一致（弹簧数值已独立复核，见 [独立复核](2026-10-03-independent-verification.md)）。本文件是**实现依据**，不是转述。

## 1. 单步子积分（半隐式 Euler）

反混淆后等价于：

```
step(dtMs, x, v, target, k, c, m, clamp, precision):
    dt   = dtMs / 1000
    Fs   = -(x - target) * k
    Fd   = -v * c
    a    = (Fs + Fd) / m
    v'   = v + a * dt
    x'   = x + v' * dt
    if clamp and ((x < target and x' > target) or (x > target and x' < target)):
        return (target, 0)
    if |v'| < precision and |x' - target| < precision:
        return (target, 0)
    return (x', v')
```

## 2. 多步推进与"分数尾步"（**关键，勿改**）

```
advance(totalMs, x, v, ...):
    steps = ceil(totalMs)
    if steps > 10000: throw
    for i = 1 .. steps:
        if i > totalMs:  substep = i - totalMs
        else:            substep = 1
        (x, v) = step(substep, ...)
    return (x, v)
```

- 循环**从 1 开始、到 ceil 结束**；最后一个子步是 `i - totalMs`。
- 因此 `totalMs = 16.666…` → 16 个 1 ms + **0.334 ms**（不是 0.666 ms）。这是原实现的真实行为，累计会略小于名义时长。
- `ceil(totalMs) > 10000` 抛错（上限 10000 ms）。

## 3. 精度与目标变更

```
effectivePrecision(x, target, precision):
    if x == target: return 1
    return max(1, |x - target|) * precision
```

- `setTargetValue(t)`：若 `t` 与当前目标相同则不变；否则校验有限、记录目标变更时间、**重算并缓存 precision = effectivePrecision(当前值, t, config.precision)**、替换目标。**不修改速度**（保速）。
- 推进时传给积分的 precision 是**目标变更时缓存的**那一个，不是每帧重算。

## 4. 每帧推进逻辑

```
advanceBy(dtMs):
    if dtMs == 0: return
    if dtMs < 0: throw "Can't go back in time"
    time += dtMs
    if disabled: return
    if dtMs >= settleTime(): snapToTarget(); return
    if mass == 0:            snapToTarget(); return
    (value, velocity) = advance(dtMs, value, velocity, target, k, c, m, clamp, cachedPrecision)
```

`snapToTarget()`：`value = target; target = target; velocity = 0`。
`isAtRest`：`target == value && velocity == 0`。

## 5. 收敛时间估算（只作吸附阈值）

```
settleTime(config):
    if config.mass == 0: return 0
    x = 0; v = 0.000001; target = 1000; t = 0
    step = 1000/60
    prec = effectivePrecision(0, 1000, config.precision)   # = 1000 * precision
    重复: step(step, x, v, target, ...); t += step
    直到 x == target 或 v == 0 或 t > 20000（上限）
    return t
```

- 归一化是 **0 → 1000**（不是 0→1），故 precision 参数在此被放大 1000 倍。
- 上限 20000 ms。首次调用后缓存（`cachedSettleTime`）。
- 仅用于 `dtMs >= settleTime` 时直接吸附；正常帧（约 16.7 ms）远小于它，因此走积分。

## 6. 回退配置与"关闭"

- 库回退配置：`{stiffness:90, damping:9, mass:1, clamp:false, precision:0.002}`。
- `mass == 0`：估算返回 0，推进直接吸附。
- `disabled == true`：推进时不做任何计算（冻结）。
