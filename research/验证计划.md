3. 保留官网快照及 hash；记录浏览器版本、DPR、刷新率、初始位置、输入事件时间戳、目标输出时间戳。
4. 提取网页位移、旋转、缩放、透明度各通道；确认数值积分、尾步、暂停恢复、收敛阈值和状态初始化对结果的影响。

## B. 样本矩阵

| 样本 | 要回答的问题 |
|---|---|
| 直线慢移、快移、突然停止 | 延迟、加减速、是否过冲及收敛时间 |
| 急转弯、连续折返、细微抖动 | 速度连续性、去抖、旋转与轨迹失真 |
| 瞬移目标、帧间不同输入频率 | 帧率敏感性与事件采样规律 |
| 单击、双击、相邻多击、远距离点击 | 自动进入、合并区间与焦点选择 |
| 点击后静止、只移动不点击 | 保持及缩回规则，区分阅读与闲置 |
| 点击前后不同长度的素材 | 是否使用未来信息，是否提前进入缩放 |
| 拖拽、选择文字、菜单／子菜单 | 指针是否落在实际操作点，点击画面是否同步 |
| 滚动后点击、输入后点击 | 滚动与输入是否影响焦点与退出计时 |
| 四角、不同宽高比、跨屏 | 视野夹紧、坐标变换、来源边界 |
| 缩放中反向切换、多次快捷键 | 速度连续、无跳变、无排队、无重复按键触发 |
| 光标换型、静止后再移动、纯纵向移动 | 热点、显示状态与网页边界行为 |

每份样本记录输入、参考原视频、参考结果、参考设置、帧率与版本；尽可能用相同输入测试不同参数，而不是凭手感重复画一遍轨迹。

## D. 实现与测试

先实现最小捕获与合成验证，再做完整设置 UI。技术验证应输出：

- 可复现的输入回放和逐帧差分；定位模型、状态、时间和渲染各类误差。
- 1080p / 60 fps 候选基线下的帧间隔分布、掉帧、CPU / GPU 使用与长时间运行结果，记录硬件型号。4K 与混合刷新率另列，不自动承诺。
- 分开测原生捕获／合成延迟、运动滤波响应、人工缓冲、会议传输延迟。报告中位数和高分位，不能只报告最优值。
- 指针点击位置和按钮响应时刻的对照，确认没有“按钮先响应、指针后到”的可见错误。
- 副屏热插拔、主副屏重排、不同缩放比例、睡眠恢复、撤销权限、来源关闭的结果。
- 腾讯会议与 Zoom 各自的版本、macOS 版本、发送端共享选择界面、另一设备接收画面。测试可见、遮挡、最小化、不同 Space、暂停、窗口尺寸变化。
- 捕获画面没有自己的预览或输出，主屏鼠标无输入延迟，观众画面没有重复光标。
- 若使用缓冲，录制会议语音与观众画面，评估讲解同步；明确是否需要声音延迟能力。

## D1. 桌面静态新线索对应的参考实验

以下先对参考软件取证，再实现产品回放工具与差分。依据见[桌面动画处理链](桌面动画处理链-官方3.7.5静态.md)与[事件／焦点链复核](官方3.7.5事件与焦点链复核.md)。参考取样只录带明确操作的短片段；不要让参考软件在分析或思考期间持续录制空闲帧。

- 点击时间两侧覆盖 500／175／130 ms；区分位置目标提前、弹簧切换、按下缩小和最终可见光标。比较单击、按住、拖拽及关闭平滑。
- 空间距离覆盖 499／500／501 个记录坐标单位，分别安排后一个／后两个事件远近和缺失；核对被去除的按下与后续松开、同时间事件排序。
- 构造同组“先停留后横移”和越组边界轨迹，核对首时刻的焦点是否已受未来位置影响；保持相同点击只改变移动轨迹。
- 在 30／60 fps 下测连续播放、单帧步进、分数帧预览、跳转、裁剪和变速；覆盖 3500 ms 初始化窗口附近及非整数毫秒子步。
- 分别移动光标、移动镜头、同向／反向同时移动、仅缩放、平移与缩放长度相等；核对主导分支、父层扣除、单侧采样方向和急停恢复。
- 用细线、文字与半透明彩色边缘观察采样权重、滤镜区域、遮罩和 alpha；不只用不透明平面认定模糊完成。
- 核对原生事件 `NSEvent.timestamp` 与视频时间的对应，`CGEventGetLocation` 的全局坐标在 Retina、多屏、窗口／区域裁切下如何映射到镜头和光标；检查静止光标换型补点与光标图片热点。

## E. 决策门槛

1. 若只取得网页参数，不能宣布桌面缩放已复刻。
2. 若参考包含未来信息，明确依赖范围与最低所需延迟；用户决定是否接受，不默认牺牲实时性。
3. 若窗口方案在要求的状态下无法持续共享，不能用“能在共享列表看见”代替真正可用；再研究虚拟显示器。
4. 参考版本、允许延迟和误差定义确认前，不给出“100% 已实现”的承诺。
5. 录制成片与演示输出分别验收；演示中的因果信息边界与可能需要的缓冲必须明确记录。若参考镜头依赖整个录制区间的未来轨迹，不能无证据宣称实时输出完全同构。

## F. 双模式与跨平台新增验收

- 来源 16:10／非标准比例到 16:9、超宽屏及竖屏：背景始终铺满，来源无非等比拉伸，Padding=0 的剩余区显示背景。
- 指针、平移、缩放分别开关运动模糊；急停后清晰、无边缘漏色、无重复模糊。
- 原始素材和事件分离：修改镜头、指针或背景后重新导出，源素材保持不变。
- 时间线切分、删除、变速、撤销、保存重开、长录音画同步及磁盘不足恢复。
- 同一工程在 Mac／Windows 上布局及运动含义一致；平台媒体、字体和光标差异明确记录。
- 先验证正常配置下的完整效果，低配档只做常规优化，不作为核心版本独立阻塞项。
- 检查所有自有文档和产品文案使用独立功能名称；参考产品名称仅用于必要的技术证据溯源。
