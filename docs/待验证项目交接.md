# 简库镜传｜待验证项目交接

更新：2026-10-02。交接对象：继续调研与开发的开发者／AI。实际实现状态以[开发进度](开发进度.md)为准。

本文汇总目前所有尚未通过运行、实测或交付验收的项目。它是待验证事项的集中清单；其他研究文档中的细节说明继续作为证据背景。**调研记录、静态代码参数和产品目标都不等于已实现或已验证。**

## 当前状态与必须遵守的边界

- 产品已开始开发；已建立 macOS 原生采集、Metal 预览、设置、菜单栏与基础截图链路，详见[开发进度](开发进度.md)。
- 本机开发工具已在上一轮安装；正式开工时仍需确认实际版本、编译器、Qt 模块和构建路径可用，并将版本记入验证记录。
- 参考基线暂定为官方 macOS Apple Silicon 版 **3.7.5-4595**。其签名、安装包哈希、静态资源定位见[官方包证据清单](../research/evidence/2026-09-30-official-3.7.5/manifest.json)。已启动官方应用核对两项设置界面；尚未完成受控录制、新工程结果或导出。
- 官方安装包静态映射出的光标／画面弹簧和模糊调用参数，不能冒充干净新工程的最终默认值。用户偏好、上个工程设置和录制类型可能覆盖基础值。
- 2026-10-01 已静态追踪[桌面动画处理链](../research/桌面动画处理链-官方3.7.5静态.md)：事件空间过滤、未来点击目标、条件弹簧、逐帧求解、焦点分组／构图和模糊采样；记录了[57 处原资源函数定位](../research/evidence/2026-09-30-official-3.7.5/animation-chain-locators.json)。这些路径仍需受控运行与输出核对。
- 用户明确要求光标平滑移动、画面平移／缩放、动态模糊及所有相关动画细节 1:1 复现；任一细节差异或遗漏都可能严重损害体验，不得擅自降级或以近似效果验收。在实现与逐项验收之前不得宣称已达成。所有项目文档及对外功能文案遵守[项目目标](项目目标.md)的独立命名硬要求。
- 用户已于 2026-10-02 明确授权开始开发；后续实现仍须按本清单逐项验证。
- 低配优化是常规优化项，不作为优先架构约束或阻塞正常机器上的完整效果。

## C. 画布比例与合成效果

- 实测 16:10、非标准比例、16:9、超宽、竖屏以及窗口源到不同观众屏比例。背景始终铺满；来源保持比例、不默认裁切；padding 为零时比例差产生的区域仍显示背景。
- 验证背景图 cover 裁切焦点、来源 contain 尺寸、padding 单位、内外框、阴影、圆角、透明边缘和亚像素运动。连续动画不能因取整方向变化产生抖动。
- 观众副屏画布跟随目标显示器真实尺寸；会议共享窗口画布内容比例与窗口外框缩放分开；录制导出比例服从项目设置。
- 比较静态背景模糊与随镜头运动的动态模糊。确认静止层和固定叠加内容不会错误地产生拖影，镜头停稳后文字恢复清晰。

## D. 录制、编辑、项目保存与导出

以下是产品能力验收项，当前均未实现或未测：

- 屏幕、窗口、区域采集；麦克风、系统音频与可选摄像头的权限、设备选择、分轨和时间戳。
- 录制／演示模式切换、停止当前任务、保留工程与恢复预设的用户流程；权限撤回、来源关闭、系统睡眠时要显示明确状态并正确恢复。
- 录制开始、暂停、结束、分段写入、长录制音画同步、异常退出恢复、磁盘不足保护和素材完整性。
- 视频素材与鼠标／点击／滚动／光标类型事件分开保存；重新编辑指针、焦点、背景和画布时不改写原始素材。
- 时间线裁剪、切分、删除、变速、静音、焦点区间编辑、撤销重做、保存、关闭重开、工程移动和版本迁移。
- 编辑预览和离线导出采用同一动画与合成定义；验证帧率、画面比例、颜色、音轨同步、编码失败恢复和导出结果。
- 普通外部视频若没有事件轨迹时，核实手动焦点体验；不把无法取得的原始指针轨迹伪装成已恢复。

## E. 性能、稳定性与 Mac 体验

- 首个性能基线建议 1080p / 60 fps，记录硬件型号、操作系统、分辨率、捕获／渲染帧间隔分布、丢帧、端到端延迟、CPU／GPU、内存增长和温度／长时间运行行为。
- 分开测屏幕捕获、滤波、背景合成、输出窗口、会议传输和同时录制带来的开销；测试预览和演示的完整效果，不默认关闭关键动画来制造流畅数据。
- 4K、混合刷新率及低配机器列为后续测量场景，不在没有数据时承诺全效果性能；先做硬件编码、缓存、纹理池、有界队列和避免无效拷贝等常规优化。
- 验证菜单、快捷键、权限引导、Retina、多窗口／Space、文件拖放、标准快捷键、触控板时间线操作和音频设备切换等 Mac 体验；确认忙碌渲染不会拖住 QML 控制界面。

## F. Windows 适配与发行检查

- 在 Windows 环境验证核心库可构建，检查 Windows.Graphics.Capture → D3D11 → Qt RHI 的纹理共享／同步／复制路径；Mac 验证成功不自动证明 Windows 通路成立。
- 验证 Windows 显示器 DPI、混合缩放、坐标、窗口捕获、系统光标、麦克风／系统音频、权限与输出窗口行为。
- 验证 Media Foundation 硬件编码能力检测、编码质量和软件兜底状态；不同显卡与驱动能力明确记录。
- 同一工程在 Mac 与 Windows 打开后，布局、时间基准、动画参数含义、字体及光标资源差异要有可解释结果。
- 最终依赖确定后检查 Qt 模块、FFmpeg 实际采用组件、许可证义务、第三方资源来源、签名、公证／安装和升级路径；不要依据未选定的方案提前宣称合规。

## G. 尚待排优先级的扩展能力

这些能力在双模式范围文档中列为后续或单独评估方向。它们尚未完成逐项竞品能力核对、成本估算和版本优先级排序，不应误读为首版已承诺交付：

- 字幕、转写、音频增强、快捷键显示、点击声音与背景音乐。
- 摄像头布局、设备录制／设备框、遮罩、高亮、GIF 和预设分享。

收到开工提示后可以先锁定核心闭环，再逐项决定这些扩展项是否纳入阶段版本。

## H. 复现结论与验收记录

“百分之百复现”仍是内部目标，结论必须绑定明确参考版本、设置、输入轨迹、帧率、刷新率和输出条件。每次验证保存原始捕获、事件时间戳、参考导出、简库输出、配置与分析脚本；对运动轨迹和图像做逐帧叠加／差分，同时记录人工观感差异。数学参数相同、有限样本相近、功能触发一致和全部行为相同是不同证据等级。

每个项目完成后追加一行记录：日期与操作者、设备／系统／软件版本、输入样本、配置、测量指标、结果、缺陷、证据文件位置、结论（通过／失败／未定）。未通过或没有数据的项目继续保持未验证状态。

## 建议接手顺序

1. 固定官方 3.7.5-4595 参考环境，隔离配置并检查默认预设后测工程有效设置；核对已定位的初稿焦点时间边界，同时复现官网运动样本。
2. 建立自动焦点事件矩阵和动态模糊逐帧基准，形成可重复的参考素材包。
3. 收到开工提示后优先验证 macOS 捕获纹理、GPU 合成、观众窗口、副屏／会议窗口这条最小闭环；并行处理点击同步与延迟。
4. 根据实测对齐画布和动画，完成录制工程、事件数据、编辑预览和离线导出，再验证长时稳定性。
5. 在跨平台核心稳定前尽早验证 Windows 编译与 D3D11 纹理通路；扩展功能及发行审查按实际依赖收尾。
