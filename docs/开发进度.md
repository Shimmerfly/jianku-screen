## 已接通的链路

- macOS 14+ 原生 ScreenCaptureKit 显示器采集，CVPixelBuffer 经 Metal 纹理进入 Qt Quick。主预览与独立观众窗口共享同一帧源，已在本机运行验证。
- 统一设置存储：参考基线、用户默认值、当前值三层；逐项“设为默认”和“复原”，JSON 原子写入。弹簧参数可逐分量设置默认值。
- 主窗口和观众窗口均关闭后，进程与菜单栏入口仍保留，采集停止。菜单提供打开应用、立即截图、退出。
- 快捷截图使用 SCScreenshotManager 在无预览窗口时独立采集，读取当前设置；背景颜色或本地图片、Padding、圆角已接入 PNG 输出。已验证 Retina 尺寸及画面方向。
- 可配置全局热键通过 macOS Carbon 注册。自动化按键未能送达系统热键事件，实体键盘触发路径尚待验收。
- 2026-10-03 依照实际录制流程重排界面：侧栏明确分为“录制”“演示”两种模式，取消醒目的品牌标识和蓝绿强调色，改为中性灰工具界面；设置仍保留画面外观、运动与光标、快捷截图分区。已目视检查主界面与设置页。
- 录制模式已接入 ScreenCaptureKit → AVAssetWriter 的实际保存链路。已在本机录制并核对一段 3360×2100、60 fps 的 H.264 MP4；演示模式仍启动独立观众窗口，已再次目视验证。
- 录制时主窗口收起，悬浮控制条显示计时与结束按钮；结束后返回主窗口。已用控制条完成第二次本机录制并核对 MP4 媒体信息。
- 用户恢复权限后，2026-10-03 当前开发包再次成功显示实时画面，并生成按当前 Padding 设置处理的 PNG。
- 依据官方 3.7.5 的 JS 资源与原生 Swift 采集器做只读复核：确认采集端同时记录事件、光标外形与时间轴；更正自动焦点点击及区间端点为向下取整，并追踪禁用区间、竖屏持续放大分支和焦点组的未来事件依赖。记录于[事件与焦点链复核](../research/官方3.7.5事件与焦点链复核.md)。

## 未完成，不能宣称 1:1 还原

- 当前 MP4 保存显示器画面（不含系统光标）。系统音频已作为 AAC 轨写入 `raw.mp4`，麦克风已独立录为 `microphone.m4a`，但音画同步与设备实机效果尚未核对；独立光标事件、工程文件、时间轴编辑与正式导出仍未实现；窗口和区域来源亦未接入。该链路不能当作完整的录屏模式验收。
- 事件采集代码目前只有未接入的草稿，尚未按参考版本同时保存点击、移动、光标外形及与视频对齐的时间戳；不能视为事件链已实现。
- 动态光标、光标平滑运动、焦点/窗口缩放、运动模糊、阴影、背景模糊尚未进入实际输出链路。设置页将相关字段标为“待接入”。所有动画在录制、预览与演示输出中均未达到 1:1 目标。
- 当前 `referenceFactory()` 的参数来自 Screen Studio 3.7.5 静态基础对象，并非实测新工程生效默认值；背景颜色是占位值，官方内置背景图片未引入。必须逐项验证后才能声称默认一致。
- 截图目前只截第一块显示器，尚未提供区域/窗口选择。当前预览与截图分别由 Qt Quick 和 QPainter 排版，仍须统一布局计算和像素级对照。
- 菜单栏常驻已验证进程保留；实体键盘热键及复杂启动/关闭交错需要补充验收。
- 当前构建是无开发者证书的临时签名包；多轮重编译曾触发 macOS 屏幕录制 TCC 拒绝。用户恢复权限后采集与截图已重新验证。后续重编译或签名策略变更仍需重验权限状态。

## 动画引擎（2026-10-03 自驱推进）

按"先核对、再实现、后对照"推进，核心已在 C++ 中实现并有单元测试。

- **D1 求解器已逐字核对并实现**：从官方包反混淆还原半隐式 Euler、`ceil(dt)` + `i - dt` 分数尾步、目标变更保速与缓存精度、`settleTime` 估算（0→1000，步长 1000/60，上限 20000ms）、`mass==0` 吸附。见 [弹簧求解器核对](../research/弹簧求解器-官方包核对.md) 与 `src/animation/SpringSolver.{h,cpp}`。
- **D2 指针姿态引擎**：事件模型、500ms 点击前瞻目标、条件弹簧（关闭 1/1/0、临近点击 530/40/1、拖拽 1000/40/1、默认 470/70/3）、旋转（400ms 窗口 × 0.03，clamp ±20°）、点击缩放（130ms 前瞻）、静止隐藏（250ms 恢复）。见 [指针链路核对](../research/指针链路-核对.md) 与 `src/animation/CursorEngine.{h,cpp}`。
- **D3 自动焦点**：区间生成（复用已验证规则）+ 区间内事件贪心分组（组尺寸 = 内容/倍率 ×(0.5,0.7)）+ 包围盒中心 + 相机变换（边缘映射与覆盖夹紧）。见 `src/animation/AutoFocusEngine.{h,cpp}`。
- **D4 动态模糊**：强度 × fps/60、主导变化二选一（位移/缩放）、位移 kernel 21 单侧 `i/20` 等权、缩放 kernel 13 权重 `4(p-p²)` + 确定性伪随机、父层运动扣除与分轴符号抑制。见 `src/animation/MotionBlur.{h,cpp}`。
- **D5 实时接入（首版）**：`AnimationDriver` 轮询系统指针（无需采集权限）→ 指针引擎 → 预览叠加平滑指针；点击触发因果放大，相机由画面弹簧驱动；预览内容层应用相机缩放/位移。见 `src/animation/AnimationDriver.{h,cpp}`、`src/mac/MousePoll.mm`、`ui/PreviewCanvas.qml`。

测试：`ctest` 4 组全通过（timeline-boundaries、spring-solver、cursor-engine、auto-focus）。

**动态模糊（2026-10-03 夜间，已按用户要求移除）**：曾实现 GLSL 位移 21 采样 / 缩放 13 采样的实时模糊，但实测放大闪烁、平移花屏，用户体验不可用，已整体回退删除（UI、驱动、着色器、构建全部移除）。参考软件的模糊机制研究仍保留在 [桌面动画处理链](../research/桌面动画处理链-官方3.7.5静态.md) 与 [画布与运动模糊](../research/画布与运动模糊.md)；将来若重做，应先解决多采样合成层的稳定性再上，且必须与参考逐帧对照。

**其他**：光标尺寸随相机倍率缩放（参考行为）；整个画面框（含圆角）作为整体被相机缩放；采集不再包含系统光标；状态灯三态（就绪绿/采集中蓝/录制中红）；演示模式新增「输出」目标选择（虚拟窗口默认 / 独占某显示器全屏）；设置面板内点击改用 `TapHandler`（修复滚动容器吞点击）；App 改用固定自签名身份 `JiankuDev` 签名，权限跨重编译保持。
